# C++

面向后端开发者的 C++ 笔记。主线按阅读顺序写：先把对象模型和 RAII 钉死，再进智能指针、STL、并发和现代 C++。对照 Go / Python 只在真正分叉的地方出现。

旧总结没有丢掉，收在 **专题笔记**：按 C 语言、语言点、深度、新标准、面试整理分组。主线讲模型和取舍，专题保留当时写全的细节。

```
基础/         入门、对象模型、指针与值类别、内存与 RAII
进阶/         智能指针、STL、虚函数、并发、现代 C++
实战项目/     把前面的点串进一个能跑的组件
面试连环问/   校招 / 社招里真实出现过的 C++ 追问
专题笔记/     旧总结：C 语言、语言点、深度长文、新标准、面试整理
```

默认 C++17，C++20/23 只在现代 C++ 篇点到。编译器以 GCC / Clang 为主，MSVC 差异会标明。
